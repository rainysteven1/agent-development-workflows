# Talk Architect

## Overview

Plan the story before building slides. A good deck cannot rescue a weak talk structure.

## Required Inputs

Lock these before drafting content if they are unknown:

- talk style
- audience type
- duration

## Workflow

1. Gather source material and constraints.
2. Define the audience's main question.
3. Compress the story into setup, development, evidence, and resolution.
4. Plan one message per slide.
5. Move secondary detail to backup rather than overcrowding the main flow.

## Output Artifacts

- a talk outline
- slide-by-slide plan
- optional speaker notes

## Handoff

Once the story is stable, move to `slidecraft` for actual deck implementation or deck review.
